How to read the graph

Rows run bottom to top: input features, read components of w_in, neurons, write components of w_out, outputs. Each component is a rank-one piece VcUcT of one weight matrix, and an importance network opens or closes it on each input.

Edges are the exact linear contributions on the current input: xjVjc, then gcacUcn into the neuron pre-activation, hnVnc, and g′cbcUck into the output. Width and depth of colour scale with magnitude. Above the output row, a black number marks each output the target model actually produces on this input (|y| above 0.05); grey numbers are position ticks every 8.

positive   negative. Square size, colour depth and edge width are scaled to the largest value each row reaches with one feature on at amplitude 1, so weak inputs look weak; values below a thousandth of that are drawn as zero. Outline weight shows the gate, from 0 to 1.

Faded squares with dotted outlines, and dotted edges, are components whose gate is closed on this input. They are drawn with what they would carry if open; the masked forward pass does not use them. Gates are computed from the target model's activations, as in VPD. Nearly invisible squares are dead components. Oracle options are the closed-form tilings of the VPD objective with analytic gates (a feature component opens only on a positive input, since a negative one produces no output; a neuron component opens when its neuron fires); Learned options are trained VPD runs. Regions (feature, neuron, null) name the oracle option (feature-aligned, neuron-aligned, or null, the all-gates-off decomposition) with the lowest VPD loss at each αimp; the side-panel plot draws the lowest oracle loss against αimp (log–log), names each region on top, and puts a dot where the selected decomposition sits.
